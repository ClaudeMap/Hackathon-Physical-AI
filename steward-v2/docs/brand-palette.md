# Steward palette

The palette drawing in the brand guidelines does not survive Markdown export, so the exact values are kept here. Hex values are design proposals; match the anodising and print colours to physical samples.

| Group | Name | Hex | Role |
| --- | --- | --- | --- |
| Materials | Brushed Steel | `#C9CED1` | Tools, lines, frames |
| Materials | Aluminium | `#E3E5E6` | Surfaces, cards |
| Materials | Graphite | `#25282A` | Dark surfaces, keys |
| Materials | Ink | `#1C1D1F` | Text and icons |
| Materials | Paper | `#F6F5F1` | App background |
| Brand | Steward Green | `#1F6F5C` | Brand and main action |
| Brand | Signal Yellow | `#FCD303` | Voice, live states, the push-to-talk key |
| Signal | Alert Red | `#B4372B` | Critical |
| Signal | Focus Orange | `#A8650C` | High |
| Signal | Circuit Blue | `#3A5F8F` | Normal |
| Signal | Quiet Grey | `#6B6E74` | Low, secondary |

Dark mode lifts Steward Green to `#5CC0A4`. Signal Yellow is a fill only: it reaches 1.3:1 against Paper, so give it a steel border or set it on Graphite. Text on it (Ink) reaches 11.6:1.
