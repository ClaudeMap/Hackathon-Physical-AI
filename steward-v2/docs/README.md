# Steward docs

Two product documents, drafted on 17 Oct 2026. The prototype in this repo implements them: `src/lib/data.ts` holds the mock data, `src/components/device/` the 3D device, and the root README explains what is real and what is mocked.

| Document | Read it | What it covers |
| --- | --- | --- |
| Product Requirements Document | [PRD.pdf](PRD.pdf) (with diagrams), [PRD.md](PRD.md) (text) | Problem, users, goals, scenarios, requirements, company context, AI architecture, device, integrations, roadmap, risks |
| Design Brief and Brand Guidelines | [brand-guidelines.pdf](brand-guidelines.pdf) (with drawings), [brand-guidelines.md](brand-guidelines.md) (text) | Brand essence, materials and finish, industrial design language, palette, type, voice, interface and sound, logo directions |

The Markdown copies keep all text and tables but replace the four drawings (architecture, roadmap, palette, logo directions) with a placeholder line. The PDFs include them. The palette values are also kept as text in [brand-palette.md](brand-palette.md).
